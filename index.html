☁️ 나만의 자동 업로더

내 컴퓨터에서 돌아가는 유튜브 자동 업로드 프로그램이에요.

이 프로그램은 어떤 건가요?
내 컴퓨터 폴더나 내 구글 드라이브 폴더에 넣어 둔 영상을, 내가 정한 시간에 내 유튜브 채널에 올려 주는 프로그램이에요. 프로그램은 사용하는 사람의 컴퓨터에서만 돌아가요. 따로 운영하는 서버가 없어요.

개인정보처리방침

1. 어떤 정보를 쓰나요?

  • 구글 로그인으로 허락받은 범위 안에서 내 유튜브 채널(영상 올리기, 공개 시간 정하기, 채널 통계 보기)과 내 구글 드라이브(영상 폴더 보기·받기, 읽기만)를 사용해요.
  • 구글 로그인 정보(토큰)는 사용하는 사람의 컴퓨터 안 프로그램 폴더에만 저장돼요.

2. 정보를 어디로 보내나요?

  • 만든 사람이나 다른 누구에게도 보내지 않아요. 모든 정보는 사용하는 사람의 컴퓨터와 구글(유튜브·드라이브) 사이에서만 오가요.
  • 제목·설명을 자동으로 쓰는 기능을 켜면, 사용하는 사람의 컴퓨터에 설치된 Claude 프로그램이 영상 파일 이름과 대본으로 글을 만들어요.
  • 구글에서 받은 정보를 광고에 쓰거나 팔지 않아요.

3. 정보를 지우려면?

  • 프로그램 폴더를 지우면 저장된 정보가 모두 지워져요.
  • 구글 계정의 보안 → 서드 파티 앱 및 서비스에서 이 프로그램의 접근 권한을 언제든 끊을 수 있어요.

이 프로그램이 구글 API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 Google API 서비스 사용자 데이터 정책과 그 제한된 사용(Limited Use) 요구 사항을 따라요.

Privacy Policy (English)

"My Auto Uploader" is a desktop program that runs only on the user's own computer. It has no server.

  • It uses Google sign-in to upload videos and set publish times on the user's own YouTube channel, read the channel's analytics, and read (read-only) video folders in the user's own Google Drive.
  • Sign-in tokens are stored only in the program folder on the user's computer. No data is sent to the developer or any third party, used for advertising, or sold.
  • Users can delete all stored data by deleting the program folder, and can revoke access at any time in their Google Account (Security → Third-party apps & services).
  • Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
